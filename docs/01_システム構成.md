
## 解析パイプライン（Phase 1 実装済み）

```
動画 D&D ──▶ ffprobe ──▶ 音声抽出(16kHz mono mp3) ──▶ TranscriptionProvider
                                                        │ vocabulary = Creator Dictionary
                                                        ▼
                                             TranscriptData(segments, words)
                                                        │
              Creator(辞書, DNA要約) ──▶ system prompt ──┤
                                                        ▼
                                            LLMProvider.complete_structured(CandidateList)
                                                        │ 重複除去・範囲正規化・スコア順
                                                        ▼
                                             Candidate × 10 + サムネ + CostEntry
```

## 書き出しパイプライン（Phase 1 実装済み）

```
採用候補 ──▶ plan_reframe: 4fps サンプル → YuNet 顔検出 → EMA 平滑化 → CropKeyframe[]
        ──▶ AssCaptionProvider: words(区間) → 文単位 ASS（句読点/文字数/間で分割）
        ──▶ ffmpeg: -ss/-to → sendcmd(crop x,y) → crop → scale 1080x1920 → subtitles(libass)
             → libx264 crf20 + aac
        ──▶ Export(path, edit_plan=EDL) + CostEntry(vision, video_processing, storage)
```

## Phase 2〜5 で足す箱（設計済み・未実装）

| Phase | 追加モジュール | 入出力 |
|---|---|---|
| 2 | `services/creator_dna.py` | 過去動画の Transcript + 音声特徴量(話速/音量/間/笑い) → `CreatorDNA` JSON |
| 3 | `services/editing_dna.py` | 元動画A + 公開動画B → 音声アライメント → `SourceComparison` → LLM で `EditingRule[]` |
| 4 | `services/auto_edit.py` | Candidate + DNA → `EditPlan`（cut/tighten_silence/caption/zoom/se/bgm） → render |
| 5 | `services/feedback.py` | EditPlan と人間修正の diff → `HumanEdit` → 理由推定 → Rule の confidence 更新 |
| 6 | Job を Celery/Redis、DB を Postgres、ストレージを S3 に差し替え | Provider 層と同じ「差し替え」設計 |

## セキュリティ / 秘密情報

- APIキーは `Settings`（pydantic-settings）だけが読み、`providers/*` の内部でしか使わない。
- フロントには `/api/status` で **provider 名とモデル名のみ** 返す。
- `.env` は `.gitignore` 済み。`.env.example` にキーは書かない。

## 同時実行モデル

- ジョブは ThreadPool(2)。動画1本あたり analyze/export は排他（409 を返す）。
- 進捗は DB の Job 行を 1 秒ポーリング（SSE は Phase6 で）。

# 06. 想定 API 費用

前提: 日本語 1 時間の長尺動画 1 本。文字起こし約 15,000 字 ≒ タイムスタンプ込みで **25k〜30k tokens**。
単価は `backend/config/pricing.yaml`（2026-09 公開価格）。実測は原価台帳（GUI の「この動画の原価」）で自動記録。

## Phase 1（1 本あたり）

| 項目 | 構成 | 計算 | USD |
|---|---|---|---|
| 文字起こし | OpenAI whisper-1 | 60 分 × $0.006 | **0.36** |
| 〃 代替 | Deepgram Nova-3 / Scribe v2 | 60 分 × $0.0043 / $0.22/h | 0.26 / 0.22 |
| 〃 ローカル | faster-whisper | $0（CPU 20〜40 分 or GPU 3 分） | 0 |
| 候補選定 LLM | Claude Opus 5 | 入力 30k × $5/M + 出力 7k × $25/M | **0.33** |
| 〃 2本目以降（同 Creator、system キャッシュ） | – | system 3k がキャッシュ読み | 0.32 |
| 〃 Sonnet 5 に落とす場合 | – | 30k × $2/M + 7k × $10/M | 0.13 |
| 映像解析 | YuNet ローカル | 10 本 × 45 秒 × 4fps = 1,800 フレーム | 0 |
| 動画処理 | ffmpeg ローカル | 10 本 × 0.5 CPU 分 × $0.002 | 0.01 |
| ストレージ | ローカル | – | 0（S3 なら 5GB × $0.023 ≒ 0.12/月） |
| **合計** | Opus + OpenAI STT | | **≒ $0.70 / 本** |
| 合計（コスト構成） | Sonnet + ローカル STT | | ≒ $0.14 / 本 |

月 30 本処理しても **$4〜21**。SaaS 化した場合、競合の $19〜29/月に対して原価率は十分低い。

## Phase 4/5（1 本あたりの増分）
- EditPlan 生成 LLM: +$0.2〜0.4（候補選定と同時に出せば増分小）
- 修正理由推定: 修正 1 件 ≒ 2k tokens → 10 件で $0.05

## コスト管理の実装
- `CostEntry(category, provider, model, quantity, unit, usd, meta)` を **API 呼び出しごと** に記録（`services/cost.py`）。
- LLM は `input / output / cache_read / cache_write` を分けて記録 → キャッシュ効果が台帳で見える。
- `GET /api/costs?creator_id=` `GET /api/videos/{id}/cost` で Creator 単位・動画単位の集計。SaaS の原価計算にそのまま使える。

# 00. 調査 — 既存技術・競合・自作/既存の分類

調査日: 2026-09-17。価格は各社公開ページ・比較記事から（変動あり。単価は `backend/config/pricing.yaml` で一元管理）。

## 1. 結論（先に言う）

- **自作するのは「Creator DNA」「Editing DNA」「候補選定の判断」「継続学習」の4つだけ。** それ以外（文字起こし・顔検出・9:16・字幕焼き込み・エンコード）は全部、既存 API か OSS。
- 文字起こしは **OpenAI（whisper-1 / gpt-4o-transcribe-diarize）を既定、faster-whisper をローカル代替**。理由: 単語タイムスタンプ＋日本語品質＋差し替えやすさ。
- LLM は **Anthropic Claude（claude-opus-5）を既定**。構造化出力 + プロンプトキャッシュで「Creator DNA を毎回全文渡す」設計が安く回る。
- 動画処理は **ffmpeg（LGPL）+ OpenCV YuNet（Apache-2.0）** でローカル完結。動画処理の API 費用はゼロ。
- 競合（OpusClip / Vizard / Klap 等）は全部「汎用バイラルスコア」。**「この編集者ならこう切る」を学習する製品は無い。** ここが差別化。

## 3. 競合サービス

| サービス | 価格 | 強み | 弱み（= 我々の隙間） |
|---|---|---|---|
| OpusClip | $15〜29/月 | Virality Score、リフレーム精度 | スコアが汎用。Creator 固有の判断を学ばない |
| Vizard | $19〜42/月（30〜100h/月） | クリップ数/コスパ、100+ 言語字幕、4K | 同上。テロップスタイルはテンプレ |
| Klap | $29/月（$0.03/分） | ポッドキャスト向け安さ | 日本語の切れ目・方言に弱い |
| Submagic / CapCut | 数$〜 | 派手字幕テンプレ | 「全部に派手字幕」型。まさに禁止したい編集 |
| Descript | $12〜24/月 | テキストベース編集、無音/フィラー除去 | 切り抜き判断は無い |
| Vrew（日本語圏で強い） | $8.99〜24.99/月 | 日本語字幕、無音カット、初心者向け | 候補選定なし、学習なし |
| OpenShorts / OpenCut (OSS) | 無料 (MIT) | 自前ホスト可能なクリップ生成 | 汎用。参考実装として読む価値はある |

**全社共通の欠落**: (1) 編集者の過去判断からの学習 (2) 方言・口癖の保持 (3) 人間の修正を次回に反映する閉ループ。この3つが本製品の核。

## 4. 分類（自作 / OSS / 外部API）

| 機能 | 分類 | 根拠 |
|---|---|---|
| 文字起こし | 外部 API（+OSS 代替） | 品質/価格ともに自作不可能 |
| 顔検出・追従クロップ | OSS + 自作（平滑化ロジック） | 検出は OSS、「どう動かすか」は Editing DNA 依存なので自作 |
| 9:16 変換・字幕焼き込み・エンコード | OSS | ffmpeg で確定 |
| 無音検出 | OSS (ffmpeg silencedetect) | – |
| **Creator DNA 抽出** | **自作** | 製品の核。LLM + 音声特徴量 + 辞書 |
| **Editing DNA（A/B 比較 → 判断推定）** | **自作** | 世の中に無い |
| **候補選定** | **自作（LLM プロンプト + DNA + 過去 Shorts 類似）** | 汎用スコアでは差別化不能 |
| 自動編集の「判断」（どこにテロップ・ズーム・SE） | 自作 | Editing DNA のルール適用 |
| 自動編集の「実行」 | OSS | ffmpeg / libass |
| **人間修正からの継続学習** | **自作** | – |
| GUI | 自作（React） | 初心者向け UX は買えない |
| ジョブ管理・原価台帳 | 自作（薄く） | Phase6 で Celery 等に置換可能な設計 |

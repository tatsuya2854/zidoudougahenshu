# 07. 技術的に難しい部分・失敗しそうな部分

確度 = 「問題が実際に起きる可能性」。

| # | 難所 | 確度 | 何が起きるか | 対策 / 判断 |
|---|---|---|---|---|
| 1 | **ASR が方言・口癖を標準語化する** | 高 | 「〜やねん」→「〜なんだ」、「なんぼ」→「いくら」。Creator らしさが文字起こし段階で消える | Dictionary を prompt/hotwords へ（実装済）。**それでも 100% は無理**。Phase2 で「辞書語の逆変換チェック」（標準形が出たら候補箇所を音声で再確認）。最終的に kotoba-whisper を Creator ごとに軽く fine-tune する選択肢（Phase6） |
| 2 | 日本語の単語タイムスタンプが粗い | 高 | Whisper の「word」はトークン塊。字幕の切れ目が 0.2〜0.4 秒ズレる | 文単位字幕（Phase1）なら実害小。語単位強調（Phase4）では forced alignment（WhisperX / ctc-segmentation）を追加 |
| 3 | **A/B の整列（Editing DNA）** | 高 | 公開動画は順序入替・BGM・テロップ・ズームで音声/映像が変質し、単純な差分が取れない | テキスト整列（文字起こし同士の DP）を主、音声指紋を従で二段構え。整列率 < 80% のペアは学習に使わない |
| 4 | 「なぜ削除したか」の推定は所詮推測 | 中〜高 | LLM が尤もらしい理由を捏造 → 間違ったルールが DNA に入る | ルールに confidence / observed_count を持たせ、**3 回以上観測されるまで active にしない**。GUI でルールを人間が承認できる画面（Phase3） |
| 5 | テロップのフォント・サイズ・色の推定 | 中 | Vision でフォント名は当てられない。近似止まり | 「太いゴシック / 丸ゴ / 明朝」等のクラス + 色 + 位置 + 大きさ比で表現。フォント本体は Creator にアップロードしてもらう |
| 6 | SE / BGM の検出 | 高 | 音声と混ざった SE の種類特定は音源分離（Demucs 等）が要り、重い | Phase4 初期は「Creator が SE ライブラリを登録 → LLM がタイミングだけ決める」。検出は後回し |
| 7 | 複数人動画の話者追従 | 中 | 最大顔を追うだけだと、喋っていない人にカメラが寄る | Phase4 で音声区間の話者分離 × 顔位置の対応付け（TalkNet 級のアクティブスピーカー検出）。Phase1 は最大顔 + 「全体+ぼかし」モードで逃げ道 |
| 8 | 長尺（2〜3 時間）で LLM の入出力が肥大 | 中 | 90k tokens 入力、候補が前半に偏る | 30 分チャンクで候補を出し、最後にリランキング。Phase1 は 1 時間想定 |
| 9 | 候補の「正解」が無い（評価不能） | 高 | 良し悪しを数値で追えない → 改善が回らない | Creator の **実 Shorts を正解ラベル** にした再現率評価（「過去動画から本人が切った区間を当てられるか」）。Phase3 のデータがそのまま評価セットになる |
| 10 | 少サンプルでの過学習 | 中 | 動画 3 本で DNA を作ると偶然を性格と誤認 | `confidence` を分数に連動、要約に「サンプル不足」を明記して LLM に断定させない |
| 11 | 公開動画の取得（ToS） | 中 | YouTube からの自動ダウンロードは規約リスク | **本人の元ファイル or 自チャンネルの YouTube Data API（captions/videos）** に限定。yt-dlp は個人検証のみ |
| 12 | ローカル処理速度 | 中 | GPU 無し PC で faster-whisper 1h = 30 分、レンダ 10 本 = 5〜10 分 | API 既定 + 書き出しは並列 2。Phase6 でクラウド GPU ワーカー |
| 13 | ffmpeg のフィルタ構文・フォントの環境差 | 中 | Windows でフォント名が違う、パスのエスケープ | `CAPTION_FONT` を .env 化、fontsdir 指定。Windows 検証は未実施（要確認） |
| 14 | LLM の refusal / 出力切れ | 低 | 長い出力で max_tokens 到達 | max_tokens 24k、stop_reason チェック済み。fallbacks（server-side）は未設定 → 必要なら追加 |
| 15 | OpenCV 5 の破壊的変更 | 低 | Haar 廃止など | YuNet + バージョン固定で回避済み |

## 最初の実動画で必ず見ること（チェックリスト）
1. 文字起こしの方言保持率（辞書語 20 個が何割そのまま出るか）
2. 候補 10 本のうち、本人が「使える」と思う本数（目標 4/10 以上）
3. 追従クロップが顔を外さないか（外すなら center / blur_fit へ）
4. 原価台帳の値が試算（$0.7）から大きく外れないか
